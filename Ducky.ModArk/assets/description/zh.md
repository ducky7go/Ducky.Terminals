## Mod Ark – 模组配置守护者
## 🧰 主要功能
Mod Ark 让你的《逃离鸭科夫》模组列表随时可备份、可还原：订阅、排序、启用状态统统打包，避免换机或实验配置时丢失。
- **完整状态备份**：一条命令保存 Steam 订阅、本地排序与启用开关。
- **安全还原**：应用前验证 JSON，并在覆盖当前配置前给出明确提示。
- **实时提示**：备份/还原全程把日志推送到终端。
**注意：这是原版模组管理器，无法作用于 BML 数据。**
## 🎮 终端命令
### 如何开启终端
1. 安装本模组所需的前置模组并启用。
2. 将鼠标移动到屏幕左下角并点击。
3. 选择 **Mod Ark**。
4. 输入 **help** 查看所有命令。
### 常用命令
- **backup \<名称\>**：以指定名称创建快照。
- **restore --yes**：从提示目录中的最新备份 JSON 还原。**--yes** 用于确认覆盖当前配置。
## ⚠️ 重要说明
### 备份命名
建议使用能描述场景的名称（例如 **更新前备份**），文件名中的非法字符会被自动替换。
### 还原确认
还原会覆盖现有配置。执行 **restore --yes** 前请检查备份 JSON 内容是否正确。
